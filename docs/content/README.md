# KingdomZombies resource inspection

Use the Windows inspection package to browse the production resource library. The package opens in the Inspection hub. Start with Items or choose Characters, Buildings/world, UI, Data/text or Audio. Register lists the 180 required asset entries. The startup selection shows the retained `common.bow` resource. Choose `IT-07` in Items for the completed Bow preview. [Windows inspection and launch guide](windows-inspection.md)

The summary shows the selected ID, name and status. Use **Show details** for provenance and editing data. For an unavailable resource, preserve the exact ID, path, field and reason with **Copy details**. Open another entry to continue inspecting, then use **Recheck resources** after restoring the required bytes.
