# Rule mechanism and proof index

[Register](register.json) owns all 85 exact source IDs, dispositions, reasons, scopes and exemption identities. This page indexes its current `binding` objects into real definitions and distinct required cases; it does not restate executable rules. The older `mechanism`/proof `status: pending` fields retain the original planned locators and final phase acceptance state. A current binding's `implemented` means a source mechanism and uniquely identified test exist, not a measured coverage, human, Linux or complete Phase 1 pass. [Verification](../workflow/verification.md) defines fresh accepted evidence.

**Acceptance timing amended 2026-11-23:** Preserve every implemented binding and test. Measured R-49/R-82 coverage and the coverage-dependent aggregate cases belong to [Phase 11](../../.planning/phases/05-ci-and-repeatable-game-testing/05-PHASE1-HANDOFF.md). Their current binding owner, delivery-timing suffix and generated pending labels identify Phase 11. Technical coverage scopes, original locators and pending status are preserved without fabricated evidence.

[Captured provenance](provenance/manifest.json) contains 85 matrix rule IDs, 84 source-heading occurrences and 24 original exemptions. Those are three different inventories: R-37 links two source headings, and source EX numbering deliberately has no EX-22. [Register validation](../../src/godot-game/tests/verification/RegisterValidator.cs) checks the original archive revision/hash and every source relationship independent of row order. [Current binding validation](../../src/godot-game/tests/verification/RuleBindingValidator.cs) checks actual symbols/settings, exact reciprocal trait/method identities and independent positive/negative obligations. The exact index rows are checked by [RuleMatrix](../../src/godot-game/tests/verification/RuleMatrix.cs).

## Scoped adaptations

Godot owns Node/Resource construction and generated partials. Handwritten scripts retain explicit initialization, nullable pre-injection staging and validation before use. Required exports fail before dereference; optional null remains valid. Exact public script/API permissions are in [visibility exemptions](visibility-exemptions.json); the sealed native fixture needs no type-level CA1852 escape. [Engine access policy](../../src/godot-game/tests/verification/EngineAccessPolicy.cs) and [native fixture](../../src/godot-game/game/proofs/Phase1.cs) require the captured engine thread and a live generation. Pure worker results return through guarded frame dispatch. Engine continuations preserve main-thread ownership; Core/service MA0004 remains enforced. See [state/engine decision](../architecture/decisions/0003-state-and-engine.md).

Generated permissions require genuine producer/package/source/path/member/span identities. [Call-site](generated-callsite-adaptations.json), [layout](generated-layout-adaptations.json), [syntax](generated-syntax-adaptations.json), [engine report](engine-adaptations.json) and [170 native spans](engine-generated-spans.json) remain independently authenticated. Eighteen exact member suppressions are checked with real adjacent/impostor/generated-origin controls. Generated filenames or comments grant no permission. Five exact LF lock paths permit only absent final LF. Test underscore names and test executable status are restricted to the proof project; the analyzer bootstrap remains a tooling edge.

Core state uses checked signed 64-bit integer milliseconds, explicit ranges and zero-time no-op; `dotnet-10.0.15/next-int64-v1` pins bounded replay semantics and common golden vectors. Identities preserve ordinal UTF-16 without case/Unicode normalization. [Strict snapshots](../../src/godot-game/core/SnapshotCodec.cs) validate detached complete state (1,048,576 UTF-8 bytes, depth 16, 1,024 records) and one atomic immutable root replacement. R-70 deliberately rejects unknown/null/duplicate input rather than inheriting permissive HTTP defaults. These are minimal contract proofs, not production saves or gameplay.

The forty-line body preference is advisory; the enforced inclusive maximum is sixty physical lines. [BodyLengthAnalyzer](../../src/godot-game/tools/code-rules/BodyLengthAnalyzer.cs) and the register define exact block/expression/global/local-function counting. The 120-character line limit uses UTF-16 units excluding terminators; four-space indentation/tab width and eight-space continuation offsets retain nearest-neighbor and non-ASCII proofs. Coverage requires exact inclusive 90% line / 80% branch counts, without rounded percentages, in both real analyzer and native-hosted managed production scopes. No measured pass exists yet.

R-43's HttpClient factory convention, R-57's per-layer DI registration, R-76's database enum storage, R-79's remote health checks, R-80's health-check tag/failure-status convention and R-85's LangApiFactory-only in-process HTTP hosts are inapplicable to the five-project Godot foundation. Their exact individual reasons and independent resolution cases stay in the register. No HTTP/EF host or provider topology is imported. [Human review](review.md) separately assesses API need, invariants, mapping intent, enum evolution and decision accuracy, including the R-79 disposition.
