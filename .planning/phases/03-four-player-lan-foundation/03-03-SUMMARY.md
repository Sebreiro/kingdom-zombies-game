## Profile schema

The private `profiles.json` schema is version 1:

```json
{"schema":1,"selected":"opaque-guid-N","profiles":[{"id":"opaque-guid-N","name":"Player 1","ordinal":1}]}
```

`selected` and `id` retain exact immutable ownership; `name` is full Unicode display text; `ordinal` is local presentation only. Neither labels nor IDs choose filesystem paths. The persistent `profiles.lock` file supplies exclusive writer ownership; random temporary files stay in the same directory and are removed after publication/failure.
